## Features

- **Scramble text hero** — Rotating headline with character-by-character decode animation
- **Cursor spotlight** — Radial gradient that follows mouse movement across the hero
- **Dark / Light themes** — Full theme system with CSS custom properties and smooth transitions
- **Scroll reveal system** — Intersection Observer-powered entrance animations with configurable delays
- **Animated counters** — Stats that count up with eased timing when scrolled into view
- **Live portfolio previews** — Embedded iframe snapshots of real client sites with browser chrome UI
- **Logo marquee** — Infinite-scroll client logo strip with pause-on-hover
- **Glass morphism nav** — Frosted glass header with backdrop blur and scroll-aware styling
- **Noise texture overlay** — Subtle SVG grain for depth and premium feel
- **Fully responsive** — Mobile-first layout from 320px to ultrawide

## Design System

The entire visual language is driven by CSS custom properties, making theme switching instant and consistent:

```
--accent:       #ff5e1a    (Orange Labs orange)
--bg-primary:   #050505    (Dark) / #f5f1eb (Light)
--font-heading: Space Grotesk
--font-body:    Inter
```

Every component reads from these tokens. Zero hard-coded colors.
